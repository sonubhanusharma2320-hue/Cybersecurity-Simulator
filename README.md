# 🔐 CyberShield-C

A simple C-based Cybersecurity Simulator that demonstrates basic cybersecurity concepts through interactive, terminal-based features.

## 🚀 Features

### 1. 🔑 Password Strength Checker
- Checks password strength.
- Evaluates password length and character combinations.
- Gives feedback on password security.

### 2. 🔒 Login Security Simulator
- Demonstrates a basic login authentication system.
- Uses demo credentials.
- Locks login after 3 failed attempts.

### 3. 🔐 Caesar Cipher
- Encrypts text by shifting alphabetic characters.
- Decrypts messages using the same shift value.
- Supports shift values from 0 to 25.

### 4. #️⃣ Text Integrity Checker
- Generates a hash value from normal text using the FNV-1a hashing algorithm.
- Demonstrates the basic concept of data integrity.

### 5. 📋 Security Activity Logs
- Records activities performed during the program.
- Displays security-related events in the terminal.

## 🛠️ Technologies Used
- **Programming Language:** C
- **Code Editor:** Visual Studio Code
- **Compiler:** GCC (MinGW)
- **Interface:** Command-Line Interface (CLI)

## ⚙️ How It Was Built
- Developed using the C programming language.
- Used functions to organize different cybersecurity features.
- Used conditional statements and loops for program logic.
- Used strings and arrays to handle user input and activity logs.
- Implemented Caesar Cipher for basic text encryption and decryption.
- Implemented FNV-1a hashing for text fingerprint generation.
- Designed an interactive menu-driven terminal interface.
